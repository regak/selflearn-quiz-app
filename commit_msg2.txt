Feature: session-varied question sampling

Expand each chapter's question list into a tagged pool with 2 variants
per "dimension" (underlying concept), and add QuestionSessionSelector +
SessionHistory so every NEW quiz session samples a different variant
per dimension than the immediately previous session, instead of
replaying the identical fixed question list every time.

- data/ContentRepository.kt: Question gains a `dimension` tag; each
  chapter's pool now has 2 question variants per dimension (5
  dimensions x 2 = 10 questions per chapter, 5 sampled per session).
  Chapter gains sessionQuestionCount (distinct dimension count) for
  UI display instead of the raw pool size.
- data/QuestionSessionSelector.kt (new): stratified sampling by
  dimension + exposure-control history (prefers a variant not used
  last session), keeps the Socratic opener first and the rest sorted
  by ascending difficulty.
- ui/QuizScreen.kt: draws its question set from
  QuestionSessionSelector.selectNewSession(chapter) instead of the raw
  chapter.questions list, re-rolled on every fresh quiz session
  (including "Retry This Chapter").
- ui/HomeScreen.kt: chapter card now shows sessionQuestionCount, not
  the full pool size.

"Review missed questions" on the results screen is untouched -- it
still re-shows the exact question the student got wrong for
remediation, deliberately not resampled.
