Replace bilingual dictionary with a real monolingual Kiswahili one

Per feedback: the dictionary was defining Swahili words only via their
English translation (bilingual, FreeDict-sourced), not actually
defining them IN SWAHILI like a real Oxford/Cambridge-style dictionary
would for English. It also only had 2,096 words, with noticeable gaps.

Fix: extract a genuine monolingual Swahili dictionary from the
Swahili-language Wiktionary (sw.wiktionary.org / "Wikamusi"), where
Swahili words are defined by Swahili speakers in Swahili.

- Downloaded and parsed the swwiktionary XML dump (107,157 content
  pages), extracting the `== {{sw}} ==` / `==Kiswahili==` section of
  each page and cleaning MediaWiki markup from the first 1-2 numbered
  glosses.
- 17,920 pages had a Swahili-language definition section; after
  quality filtering and de-duplication, kept 16,156 clean entries.
- Cross-referenced with the previous FreeDict bilingual data to attach
  an OPTIONAL bonus English translation (~1,357 entries got one) --
  but the Swahili definition is now the primary, always-present field.
- data/SwahiliDictionaryRepository.kt: DictionaryEntry now has
  swahiliDefinition (primary) and englishMeaning (optional bonus)
  instead of a single English-only `meaning` field.
- ui/SwahiliDictionaryDialog.kt: cards show "MAANA (KISWAHILI)" first,
  with an "ENGLISH" section only when a bonus translation exists.
  Search now matches headword, Swahili definition, or bonus English.
- THIRD_PARTY_NOTICES.md / THIRD_PARTY_WIKTIONARY_LICENSE.txt: added
  attribution and license text for the Wiktionary-derived content
  (CC BY-SA 4.0 + GFDL), alongside the existing FreeDict GPLv2+ notice
  for the bonus translations.

Honest caveat kept in the docs: this is still real third-party data
from a volunteer-edited wiki, not an institutionally curated
dictionary -- strong on everyday vocabulary, thinner on specialized
terms (some of this app's own geography/science vocabulary still
isn't covered).
