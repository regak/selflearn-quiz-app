Replace per-chapter glossary with a standalone Swahili dictionary

Per feedback: the dictionary should NOT be tied to chapter content at
all -- it should be a general-purpose standalone reference dictionary,
like a real pocket Swahili dictionary, reachable the same way
regardless of which (or whether any) chapter is open.

- Removed Chapter.glossary / GlossaryTerm and the old chapter-scoped
  GlossaryDialog entirely.
- Added a bundled, chapter-independent dataset of 2,096 unique
  Swahili headwords (app/src/main/assets/swahili_dictionary.json,
  ~95KB), built by merging and de-duplicating the FreeDict project's
  Swahili-English (2,675 headwords) and English-Swahili (1,450
  headwords) open dictionaries. See THIRD_PARTY_NOTICES.md and
  THIRD_PARTY_DICTIONARY_LICENSE.txt for attribution/license (GPLv2+).
- data/SwahiliDictionaryRepository.kt: loads and caches the bundled
  JSON from assets via org.json (no new Gradle dependency needed).
- ui/SwahiliDictionaryDialog.kt (new, replaces GlossaryDialog.kt):
  same navy/gold dictionary-app visual style as before, now backed by
  the full word list with a live search box filtering by headword or
  English meaning.
- HomeScreen/ReadingScreen/QuizScreen: all three dictionary buttons
  now open this exact same standalone dictionary instead of a
  per-chapter word list.
